# Design drafts

These are raw outputs of design workflows. They are design notes, not decisions.

The coordinator condenses each one into `docs/design/<name>.md` and turns it into:

- backlog tasks;
- progress rows;
- owner questions;
- one-line legal points.

Where a draft and `docs/decisions.md` disagree, `docs/decisions.md` wins. `docs/handoff.md` lists the drafts and their state.
