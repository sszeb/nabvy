# Actor app integration guide — condensed

**One-screen summary.** Two documents landed in `sebtimize/fb-scrap-engine` on 2026-09-24: `docs/APP_INTEGRATION_GUIDE.md` (commit `f60257b`, 14:22 UTC; read here at HEAD, blob `abac9a8d`) gives the actor's full v3 input/output contracts for build 1.0.82, job recipes with settled costs, and Supabase/Edge Function recipes; `docs/design/COPY_ADVERT_SPAM.md` gives a hand-labelled copy/trade/scam-label design. ## Contracts

**Input v3** (`fb-scrap-engine/docs/APP_INTEGRATION_GUIDE.md:69-96`, consumed by `apify-gateway`): `inputVersion:3`; `searchTerms` string[]≤20, ≤80 chars each; `cityId` 5–30 digit string; `radiusKm` 1–500 (no measured effect, leave unset); `sort` `default`\|`newest`; `listingIds` string[]≤1000, 1–30 digit entries; `includeDetails` bool (default true); `detailRoute` `graphql`\|`page` (default graphql); `browserFallback` bool (default true, forced false below 1,024 MB); `detailSessionSize` 5–100 (default 40); `maxListings` 1–5000; `maxPagesPerSearch` 1–100 (default 20); `maxDetails` 0–6000; `maxRequests` 1–20000 (formula given, leave unset); `maxRunSeconds` 10–3600 (default 900); `detailConcurrency` 1–8 (default 4); `useDetailCache` (keep false); `sourceDiagnostics` (keep true); `proxyConfiguration` `{useApifyProxy:true, apifyProxyGroups:["RESIDENTIAL"], apifyProxyCountry:"GB"}`. A wrong type or out-of-range integer returns HTTP 400, nothing charged; a code-level rule violation (unknown key, a missing companion field, no source) starts and charges a `FAILED` run with no dataset rows (`…:96`).

**Output** (`…:126-270`, consumed by `listing-ingest`/`detail-evidence`/`run-coverage`/`details-queue`): row discriminator `recordType` `listing`\|`sourceOutcome`; `money{kind,amountMinor,currency,exponent,display,rawAmount}` — store `amountMinor`+`currency`, never `price`/`currency` (item values can disagree with card values on a detailed search row, `…:152`); `descriptionStatus` `full_verified`\|`partial`\|`missing`; `detailOutcome` (item 5 above); `sourceStopReason`/`route` (item 6); `photos[].id` for keys, `photoUrls`/`imageUrl` `oe=` hex-Unix-seconds expiry ≈104–108 h after collection (`…:188`); `directItemUnresolved:true` placeholder shape (item 8); city page read order `locationDetails.reverse_geocode.city_page` → `sourceFields.search.location.reverse_geocode.city_page` → `conflicts[field=locationDetails].searchValue…` → (`listingIds`-only rows) nearest seeded town by coordinates within 40 km (`…:186`).

## Costs

Guide's measured/settled figures only (`…:298-311`, `…:1292-1312`); none invented. Early check (newest, page 1): $0.0022 single term settled, $0.0046 for 3 terms batched ($0.0015/term); a 1.0.82 live read (unsettled, ~1 min) was $0.0048/3 terms. Catch-up (pages 1–4): *≈$0.005/term* (estimate). Full sweep: $0.031 long `3090` (55 pages), $0.023 `sofa`, $0.003 short 10 km feed; *≈$45/month/term* if run every 30 min. Details, `graphql`: $0.00092/listing (97 KB proxy); `page`: $0.00166/listing (170 KB proxy), −45% on graphql. Re-check by ID: as details; the owner's example `Pc` listing settled at $0.002. Monthly per region (lean, 4 terms): *≈$15*; standard (6 terms): *≈$31–32*. Copy-advert's label-driven detail fetches: capped 200/day, *≈$5.52/month* at cap. Plan ceilings: Creator $85/month, 10 GB residential proxy, 32 concurrent runs; unit prices $0.20/CU, $8/GB residential. These reconcile with, and do not change, `actor-integration.md` 2.16's figures — cite the guide as the primary source going forward.

## Recipes

Matched against `nabvy/services/apify-gateway/README.md`. The guide's own pattern (`…:348-629`): four Edge Functions (`start-run` — the only spender, budget-gates then claims-and-starts under an advisory lock; `apify-webhook` — replies 200 at once, backgrounds the sync; `gateway-sweeper` — every minute, polls stalled runs and reconciles ambiguous starts by canonical `INPUT` equality; `settle-costs` — every 5 minutes, re-reads cost ≥10 minutes after finish) driven by `pg_cron`+`pg_net`, all `verify_jwt=false`, secret-checked in constant time. This matches Nabvy's built `apify-gateway` Edge Function + `apify-gateway-watch` task 1:1 in shape (claim under lock, budget gate at claim time, settle ≥10 min after finish, idempotent by job/run ID, webhooks at-least-once with GET-truth reconciliation). No recipe change needed; it is further evidence for the A1+A2+B1+C1 runtime choice in `actor-integration.md` §4.
