# Sources for the Nabvy terms and policies

This file maps each section of the four drafts to what shaped it:

- the Apify and Supabase clauses that inspired its structure or approach (the owner asked for these as the model);
- the big-tech clauses whose position it matches (the owner's instruction "match big tech", `docs/decisions.md`, "Policies and conduct match big tech").

It gives URLs and topics only, and it quotes no text. The Nabvy wording in all four drafts is original. No legal analysis is given here; points for a lawyer are in `LEGAL-REVIEW.md`.

Drafts: [terms.md](terms.md), [refunds-and-cancellation.md](refunds-and-cancellation.md), [acceptable-use.md](acceptable-use.md), [fair-use.md](fair-use.md).
